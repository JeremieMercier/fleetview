# Documentation API Masternaut

Déposer ici le PDF de la documentation de l'API Masternaut (Michelin
Connected Fleet).

Tout le contenu de ce dossier est **ignoré par git** (documentation
propriétaire), à l'exception de ce fichier.

Les identifiants de l'API ne se stockent **jamais** ici ni ailleurs dans le
dépôt : ils se saisissent dans GLPI via *Configuration → Générale → onglet
Fleetview* et sont chiffrés en base de données (GLPIKey).
